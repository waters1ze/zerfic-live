# 🎙️ Zerfic Live — Официальное расширение голосового компаньона

**Zerfic Live** — интерактивный голосовой ИИ-собеседник для системы **Zerf Note**. Общайтесь с живым анимированным персонажем Зерфиком голосом в реальном времени, планируйте день, обсуждайте идеи и получайте структурированные ответы с мужской озвучкой и естественной человеческой речью.

---

## 🌟 Ключевые возможности

- 🗣️ **Живая человеческая речь**: естественные междометия размышления (*«а...»*, *«так, погоди»*, *«сейчас гляну»*), паузы и интонации.
- 👨 **Мужские тембры Зерфика**:
  - `Зерфик (Фирменный)` — задорный, живой, молодой голос.
  - `Зерфик (Интеллект)` — спокойный, глубокий бархатный тембр.
  - `Зерфик (Драйв / Коуч)` — бодрый, мотивирующий голос для работы и тренировок.
- 🎭 **Живая мимика и анимации**:
  - `chair_sit` — Зерфик достает стул и присаживается для вдумчивого диалога.
  - `waving_arms` — машет руками при приветствии и прощании.
  - `jump_and_float` — прыгает и парит от радости при выполнении целей.
  - `speaking` — анимация речи и рта в такт звуковой волне.
- 🧠 **Глубокий контекст**: знает все ваши активные задачи, заметки, цели, дедлайны и встречи.
- 📱 **Telegram Voice Reply**: при отправке голосовых сообщений в Telegram-бота Зерфик отвечает такими же живыми голосовыми сообщениями!

## 🚀 Как опубликовать расширение в Zerf

1. **Запушьте этот репозиторий на GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Zerfic Live"
   git remote add origin https://github.com/ВАШ_АККАУНТ/zerfic-live-extension.git
   git branch -M main
   git push -u origin main
   ```

2. **Зайдите на сайт Zerf в раздел Разработчика** (`/developer` или Настройки → Студия расширений).
3. **Нажмите «Опубликовать расширение»** и вставьте ссылку на ваш GitHub репозиторий.
4. Манифест автоматически проверится, и карточка **Zerfic Live** появится в каталоге расширений маркетплейса!
